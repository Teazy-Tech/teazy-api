# Prompt inventory (AI-00)

Every prompt and model call in the 17 legacy Supabase edge functions and `_shared/curriculum.ts`, taken from `Teazy-Tech/teazy-lesson-assistant` at commit `63117cd` (20 Oct 2026). If production (`teazy-legacy`) has moved on since then, re-check the functions marked below before AI-04 baselines them.

All legacy calls go through one third-party OpenAI-compatible gateway with a single key. The new gateway (`src/ai/gateway.ts`) calls Gemini and OpenAI directly, so model ids lose their `google/` and `openai/` prefixes.

## Findings worth carrying into the new code

1. **Two JSON styles.** `generate-resource` uses strict JSON schema output. Quiz and all three assessment functions ask for JSON in free text, strip code fences and call `JSON.parse`; a parse failure is a 500 for the teacher. These are the first candidates for `generateStructured` (AI-03).
2. **Silent defaults after parsing.** `assess-script` and `assess-batch` fill missing scores with 0, missing confidence with 80 and missing grades from the percentage. A missing confidence therefore never triggers review. With schema validation this should become a validation failure plus one retry, not a default.
3. **Different marking prompts for the same job.** `assess-batch` uses a shorter prompt than `assess-script` (shorter curriculum focus and subject guidance, no feedback rules). The same script can be marked differently on its own and in a batch. Worth one shared prompt in AI-14/AI-15.
4. **Prompt injection.** Only `generate-resource` fences user input (`<request>`) and tells the model to treat it as content. Lesson, quiz and assessment prompts paste teacher and student text straight in.
5. **Unused code and mismatched names.** `buildReviewPrompt` and `shouldGenerateDiagrams` in `_shared/curriculum.ts` are never called. Curriculum names differ between functions: lessons and `assess-writing` use `Kenya` and `Ghana`, while `assess-script` and `assess-batch` use `Kenya CBC` and `Ghana Curriculum`, so an unmatched name silently falls back to the Nigeria (NERDC) text. One shared curriculum list would fix this.
6. **No fallback model anywhere.** A 429 or 402 from the gateway goes straight to the teacher. AI-01 adds the fallback.
7. **Student text in logs.** `assess-script` and `assess-writing` log the raw model response on a parse failure, which can contain quoted student writing. The new code must not (README rule 9).
