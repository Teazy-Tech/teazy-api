# Slide and worksheet images (v1)

Function `slide-images`. Model `openai/gpt-image-2.5-sunburst` via `/v1/images/generations`, 1536x1024, quality low. 1 to 8 prompts per call; the prompts come from the client (slide or worksheet `imagePrompt` fields).

Copied verbatim from `Teazy-Tech/teazy-lesson-assistant` at commit `63117cd`, `supabase/functions/`. Text inside each block is the exact source, including the `${...}` placeholders the legacy code fills in at run time. v1 is the legacy baseline: do not edit it. Changes go in `v2.md` and must pass the eval run (AI-04).

## Call, including the final prompt template

Source: `slide-images/index.ts` lines 27-41

```text
    const one = async (p: string): Promise<string | null> => {
      const r = await fetch("https://ai.gateway.lovable.dev/v1/images/generations", {
        method: "POST",
        headers: { Authorization: `Bearer ${key}`, "Content-Type": "application/json" },
        body: JSON.stringify({ model: MODEL, prompt: `${p}. Topic: ${topic}. ${styleText}`, size: "1536x1024", quality: "low" }),
      });
      if (!r.ok) {
        if (r.status === 402 || r.status === 429 || r.status === 403) blocked = r.status;
        console.error("image error", r.status, await r.text());
        return null;
      }
      const j = await r.json();
      const b = j.data?.[0]?.b64_json;
      return b ? `data:image/png;base64,${b}` : null;
    };
```
